02 / Know what is listed

Check the catalog.
Choose deliberately.

Model names and free tiers change. The new CLI reads OpenRouter's public catalog and shows when it checked. No key, no inference call, no local-model scan.

Legacy aliases keep their exact IDs. Missing models fail clearly. A former free preset never silently becomes a paid replacement.

# Check a legacy alias without a substitution

npx anymodel check qwen

Listed ≠ account access, endpoint health, coding quality or native subscription entitlement. Advertised tools still need a real execution check.

Practical questions

Before you connect.

Do I need AnyModel for SpecWeave Studio?

No. Studio's native frontier path uses the official agent runtime. OpenCode, Pi and ACP integrations also provide existing routes for hosted models. Add an adapter only for a specific compatibility need.

Will a cheaper model save me money?

Only if the accepted work saves more than setup, review and repairs cost. Native subscription capacity may already be paid for. Compare time to acceptance, interventions, incremental API spend and quota consumption separately.

What happens when a free preset disappears?

The exact legacy ID fails its catalog check. It is never replaced with a paid model. Run anymodel models --free and choose a currently listed model explicitly.

Are existing local setups removed?

No. Explicit local providers and settings remain available to existing users. They were not evaluated with local inference for this hosted release. Legacy setup guide ↗

Where do requests and credentials go?

Your proxy sends requests to the explicitly configured API provider, using that provider's credentials. A remote deployment has its own operator and trust boundary. Use token authentication, keep provider keys separate and verify the destination before sending private project content.
