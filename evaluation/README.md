# Bounded hosted compatibility pilot

This is an opt-in evaluator, not a benchmark leaderboard. It never starts a local model. The three single-file repair tasks are frozen public AnyModel 1.17.0 code; `fixtures/provenance.json` records source ranges and hashes. Hidden acceptance checks live in `scoring.mjs`, outside each agent workspace. The frozen defects must fail the scorer, and the implemented repairs must pass before any live evaluation.

Use Node 22.20.0. `run-pilot.mjs --help` is safe and makes no model requests. Live execution requires `--execute`, an exact model ID, and an external artifact directory. The root operator supplies the existing authorized OpenRouter key through `OPENROUTER_API_KEY`; it is never copied into the scratch repository or config. A loopback gate owns the real key and gives the agent a random sentinel credential. All hosted requests pass through that gate, including the AnyModel comparison arm. No silent model substitutions are accepted. A frozen catalog row must advertise tools and valid token pricing.

```sh
node evaluation/run-pilot.mjs --execute --arm frontier-direct --model EXACT_OPENROUTER_ID --task all --root /absolute/integration/source --catalog /external/frozen-catalog.json --budget-file /external/pilot-budget.json --out /external/pilot
node evaluation/run-pilot.mjs --execute --arm frontier-proxy --model SAME_OPENROUTER_ID --task all --root /absolute/integration/source --catalog /external/frozen-catalog.json --budget-file /external/pilot-budget.json --out /external/pilot
node evaluation/run-pilot.mjs --execute --arm qwen-direct --model EXACT_QWEN_ID --task all --root /absolute/integration/source --catalog /external/frozen-catalog.json --budget-file /external/pilot-budget.json --out /external/pilot
node evaluation/run-pilot.mjs --execute --arm native --model EXACT_NATIVE_CODEX_ID --task all --root /absolute/integration/source --out /external/pilot
```

The hosted pilot shares **one $4.75 ledger across every arm/cell**. The remaining $0.25 of the total authorized $5 is reserved for the independently run protocol smoke with its own ledger. Never delete/reset these ledgers to continue a stopped pilot. The gate reserves a conservative text-only upper bound before each request: UTF-8 payload bytes plus 4,096 framing tokens, no caching discounts, output cap and any listed per-request fee. Reservations are deliberately not refunded; they are not actual spend. If model/provider pricing changes after the catalog snapshot, this estimate is not authoritative, so execute promptly after catalog verification. Missing provider usage/cost stays unknown. Native Codex uses existing subscription/authentication; its monetary cost is unavailable and is not charged to this API ledger.

OpenCode 1.14.33 uses `--pure`, isolated XDG config/data/cache/state, disabled external skills/plugins/model fetching and only the explicit OpenRouter provider. Permission policy allows file read/edit/search inside the scratch project and denies shell, external directories, delegation and web tools. Each task gets at most six agent steps, six provider requests, 2,048 output tokens per request and six minutes. The proxy arm changes only base URL, using the same OpenCode provider/model configuration.

Codex CLI 0.161.0 uses `--ignore-user-config --ephemeral --sandbox workspace-write` and a fresh scratch Git repository. It uses existing account authentication without copying OAuth files. The six-minute timeout is enforced; this harness does not claim a hard native step/output-token cap. This is a **Codex CLI baseline, not a live SpecWeave Studio session**. Its tools and billing context differ from OpenCode; comparisons do not isolate model capability or cost.

Every cell saves the original task/source/test hashes, requested/observed model, runtime, source revision, raw redacted JSON events, stderr, diff, forbidden-file changes, hidden-test result, API receipts, timestamps and timeout/error state. Artifact correctness and clean agent completion are separate. A cell passes only when both pass with no forbidden changes. Tool/runtime errors are retained; no retry or intervention is silently hidden. No resumption, context-pressure, multi-agent or large-repository claim follows from these three tasks.

`../scripts/verification/offline-tests.mjs` runs every test in `test/`, `worker/test/`, `catalog-test/`, and `evaluation/test/` with credentials removed and a preloaded network guard. Only HTTP servers opened by the current test process are reachable; blocked attempts fail even if caught. It exports TAP, LCOV, raw V8 and JSON to an external directory and checks aggregate runtime line coverage. This combines unit/fixture integration coverage and does not independently satisfy a 100% live E2E coverage target.

`../scripts/verification/release-receipt.mjs --help` checks a supplied registry metadata document/tarball, integrity, expected version/gitHead, no frozen `cli.js`, required catalog/runtime files and isolated CLI version/help. Its result is package proof, not deployment or globally installed-package proof.
